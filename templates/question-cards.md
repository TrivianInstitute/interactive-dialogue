# Question cards

Choose one question that serves the present need. Modify the wording freely.

| Need | Question or turn |
| --- | --- |
| Clarify | “When you say ‘accessible,’ do you mean physical access, cost, language, or something else?” |
| Reflect | “I understand your suggestion as ___. Have I missed a condition?” |
| Contribute | “My experience suggests ___. How would that change the options?” |
| Expose an assumption | “What must be true for that recommendation to work?” |
| Compare | “Give me two options with different tradeoffs.” |
| Test | “What case would make this answer fail?” |
| Disagree | “I see a conflict with ___. Can we examine it?” |
| Check | “Which claim needs a source? Where can I inspect the original?” |
| Learn | “Give me a hint, then let me try before explaining.” |
| Repair | “You changed my goal from ___ to ___. Return to the original constraint.” |
| Decide | “Summarize the options. I will choose using ___ as my criteria.” |
| Stop | “I have enough for now. What remains unresolved?” |

These are conversational scaffolds, not commands that establish technical permissions or guarantee model behavior.
